# ExecutionPlan

Plan generated by the coordinator agent describing tasks to be executed by specialized agents.

---

## Fields

### plan_summary

- Type: string
- Required: no
- Description: High-level description of the execution strategy.

---

### tasks

- Type: array
- Required: yes
- Description: List of tasks that must be executed.
- Items: Each item follows the structure defined in [task.md](./task.md).
